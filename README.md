# finratio

Small, dependency-free financial ratio helpers in Python — gross/net margin,
ROE, ROA, D/E, current and quick ratio, interest coverage, and CAGR.

Demo repository for a Boom Leverage video on running Claude Code in the cloud:
the test suite is intentionally thin, so there is real work to hand off.

```bash
pip install -e ".[dev]"
python -m pytest -q
python examples/sample_company.py
```

All numbers in `examples/` are fictional.
